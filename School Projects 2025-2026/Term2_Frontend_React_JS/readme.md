## Projects Included

### Country App
A React application that works with country data and demonstrates component structure, filtering, and API-driven frontend development.

A JavaScript utility toolkit containing multiple interactive tools for string formatting, validation, coordinate handling, MIME checking, URL creation, and dynamic media embedding.

### Maserati Site
A multi-page automotive-themed website focused on frontend design, navigation systems, media integration, and custom styling.

### Midterm Group Project
A collaborative frontend project demonstrating multi-page site structure, JavaScript interaction, and organized styling/assets management.
