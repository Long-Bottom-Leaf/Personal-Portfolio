# Term 3 Database Projects

This folder contains database development projects completed during Term 3 coursework. These projects focused on relational database design, SQL development, normalization, backend database integration, API connectivity, and query optimization.

---

## Topics Covered

- Relational database design
- Entity Relationship Diagrams (ERD)
- SQL queries and joins
- Database normalization
- CRUD operations
- Backend API integration
- MongoDB and Mongoose
- Express.js database connectivity

---

## Projects Included

### Bookstore Database Design
A complete bookstore database design project including relational schema planning, ERD creation, and database structure documentation.

### CD API Express MongoDB
A backend API project using Express.js and MongoDB with Mongoose for handling database operations and API endpoints.

### Midterm Solo Project
A full database-focused project containing SQL table creation, data insertion scripts, normalization explanations, and query development for relational database operations.

### SQL Queries
A collection of SQL practice problems demonstrating query writing, filtering, joins, sorting, grouping, and database problem-solving techniques.
