## Projects Included

### Fullstack Database Solo
A full-stack web application using Node.js, Express, EJS, and database integration. The project includes authenticated and unauthenticated views, reusable partials, signup functionality, and utility-based backend organization.

### Java Group Project
A collaborative Java application featuring modular package organization for gym membership management, workouts, merchandise, enrollment systems, and user handling. Includes SQL schema setup and seeded database content.
