Term 3 Java Projects 💻

This repository contains multiple Java projects completed for Term 3, showcasing object-oriented programming concepts like encapsulation, aggregation, and composition.

Project Overview

This repository includes two main projects:

1️⃣ Credit Card Management 💳

Person.java – Represents a person with name and address

Address.java – Stores address details

Amount.java – Handles transaction amounts

CreditCard.java – Represents a credit card, tracks balance and transactions

Features

Encapsulates personal and financial data

Allows multiple credit cards per person

Tracks balances and transactions

Demonstrates class composition

2️⃣ Geometric Shapes & Campus Mapping 🏫

MyPoint – A 2D point (x, y)

MyLine – Connects two points; calculates length & gradient

MyRectangle – Defined by two points; calculates width, height, area, perimeter

MyCircle – Circle with center point and radius

CampusMap – Aggregates buildings, walkways, and fountains to model a campus

Features

Add buildings, fountains, and walkways dynamically

Calculate total lengths, areas, and gradients

Check existence of specific walkways

Demonstrates aggregation and composition

How to Run ▶️

Compile all Java files in the project folder.

Run the provided test drivers:

TestCreditCard.java for the credit card project

TestMyLine.java, TestMyRectangle.java, TestCampusMap.java for geometric/campus mapping
