# Term 3 Java Projects

This folder contains Java programming projects completed during Term 3 coursework. These projects focused on object-oriented programming, class design, inheritance, file handling, database connectivity, Java application structure, and problem-solving using Java.

---

## Topics Covered

- Object-oriented programming (OOP)
- Java class design
- Inheritance and polymorphism
- Encapsulation and abstraction
- File input and output
- JDBC database connectivity
- SQL integration with Java
- Modular application structure
- Testing and debugging

---

## Projects Included

### Assignment 2
A collection of introductory Java exercises focused on user interaction, problem-solving, and foundational programming concepts including map navigation logic and credit card validation.

### Assignment 3

#### College Student
A Java project demonstrating inheritance, person/student/teacher class structures, and object-oriented modeling for educational systems.

#### Movable Point
A coordinate-based Java application focused on point manipulation, object interaction, and class relationships.

#### Shapes Assignment 1
A geometry-focused project implementing shape classes such as circles, ellipses, triangles, and equilateral triangles using inheritance and polymorphism.

#### Shapes Assignment 2
An extension of the shapes project with additional object-oriented structure, reusable shape behaviors, and geometric calculations.

### Drug Tracking Program
A Java database application for managing patient and drug records using PostgreSQL and JDBC connectivity. Includes SQL table creation, entity classes, database managers, and file/database operations.

### Java Class Testing
A testing-focused Java project demonstrating custom account and date classes along with test-driven validation and output verification.
