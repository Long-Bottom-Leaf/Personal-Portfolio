# Term 4 Data Structures and Algorithms

This folder contains Java projects completed during Term 4 coursework with a focus on data structures, algorithms, object-oriented programming, and problem-solving techniques.

---

## Topics Covered

- Object-Oriented Programming (OOP)
- Linked Lists
- Doubly Linked Lists
- Data Structures
- Algorithm Design
- Collections and Data Management
- Class Design and Inheritance
- Java Application Development

---

## Projects Included

### Animal Shelter Management System
A Java application that manages animals within a shelter environment using object-oriented principles, inheritance, and class relationships.

### Singly Linked List Implementation
A custom linked list implementation demonstrating node management, traversal, insertion, and deletion operations.

### Undo/Redo Manager
A doubly linked list application that simulates undo and redo functionality using custom data structure logic.

### Movie Theatre Seating System
A reservation and seating management application that demonstrates data organization, validation, and user interaction.

### Temperature Analyzer
A data analysis application used to process and evaluate temperature-related datasets.
