# Term 4 Final Projects

This folder contains capstone and final projects completed during Term 4 coursework. These projects focused on enterprise Java development, REST API design, database integration, data structures, software architecture, testing, and deployment practices.

---

## Technologies Used

- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- Docker
- Maven
- Postman
- REST APIs
- Data Structures & Algorithms

## Projects Included

### Airport Management API

A full-stack backend REST API designed to manage airport operations and related entities.

#### Features
- Airport management
- Airline management
- Aircraft tracking
- Flight scheduling and status management
- Gate management
- Passenger management
- API security and validation
- Automated testing

#### Skills Demonstrated
- REST API development
- DTO pattern implementation
- Entity relationship modeling
- Database integration with JPA
- Spring Security
- Docker containerization
- Unit and integration testing

---

### Warehouse Inventory System

A Spring Boot inventory management application designed to manage products, customers, and orders while implementing custom data structures and business logic.

#### Features
- Product management
- Customer management
- Order processing
- Inventory tracking
- Repository and service architecture
- Custom data structure implementation
- Automated testing
- API endpoint development

#### Skills Demonstrated
- Spring Boot application architecture
- CRUD operations
- Service and repository layers
- Custom data structures
- Business logic implementation
- Database persistence
- Backend testing
- API development
